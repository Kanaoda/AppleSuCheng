# 蘋果速成 v0.2.0

Windows 速成手感的 macOS 繁體輸入法。

## 安裝（一般用戶）

1. 下載 `AppleSuCheng-0.2.0-macOS.zip` 並解壓  
2. 雙擊 **安裝.command**，輸入密碼  
3. 系統設定 → 鍵盤 → 輸入法 → 加入 **蘋果速成**

若列表未出現，請登出再登入一次。

## 此版本

- 產品名：蘋果速成 / Apple SuCheng  
- Bundle ID：`com.applesucheng.inputmethod.SuCheng`  
- 單碼直出、Shift+數字關聯、空白翻頁、日月金木預編輯  
- 自產「速」選單圖示
