# Upstream

This `frontend/` tree is a GPL-3.0 fork of the Rime project's official macOS
InputMethodKit front-end.

- License: GPL-3.0 (see `LICENSE.txt`)
- Bootstrap clones the upstream git URL via `packaging/scripts/bootstrap_frontend.sh`
  (`ASC_UPSTREAM_URL`, or the script's default construction).

Product branding, bundle IDs, themes, and schemas for 蘋果速成 / Apple SuCheng
are applied on top of that fork.
